═══════════════════════════════════════════════════════════════════════════════
  USAGE WORKFLOWS
═══════════════════════════════════════════════════════════════════════════════

WORKFLOW 1: Quick Start (Recommended for first-time users)
─────────────────────────────────────────────────────────
1. Configure GitHub Secrets (AZURE_CLIENT_ID, AZURE_TENANT_ID, etc.)
2. Go to Actions → "Deploy Microsoft Fabric Assets"
3. Click "Run workflow"
4. Fill in the parameters via UI
5. Click "Run workflow" button
⏱️  Time: 5 minutes

WORKFLOW 2: Configuration-Based (Recommended for production)
─────────────────────────────────────────────────────────────
1. Copy example config: cp config/parameters.example.json config/parameters.json
2. Edit config/parameters.json with your values
3. Commit and push to main branch
4. Automatic deployment triggers
⏱️  Time: 2 minutes (after initial setup)

WORKFLOW 3: Local Development (Recommended for testing)
────────────────────────────────────────────────────────
1. Edit config file
2. Run: ./scripts/Validate-Config.ps1
3. Run: ./scripts/Test-LocalDeployment.ps1 -DryRun
4. Run: ./scripts/Test-LocalDeployment.ps1
⏱️  Time: 10 minutes (includes testing)

WORKFLOW 4: Multi-Environment (Recommended for enterprises)
────────────────────────────────────────────────────────────
1. Create dev config: config/parameters.dev.json
2. Create prod config: config/parameters.prod.json
3. Deploy to dev first
4. Test and validate
5. Deploy to prod via workflow or push
⏱️  Time: Varies by environment

═══════════════════════════════════════════════════════════════════════════════
  GETTING STARTED
═══════════════════════════════════════════════════════════════════════════════

Step 1: Prerequisites
─────────────────────
□ Azure subscription with Microsoft Fabric enabled
□ Azure AD application (Service Principal) created
□ Fabric Admin permissions or workspace creation rights
□ GitHub repository access

Step 2: Configure Secrets
──────────────────────────
Add to GitHub repository secrets:
• AZURE_CLIENT_ID
• AZURE_TENANT_ID
• AZURE_SUBSCRIPTION_ID
• SQL_CONNECTION_STRING (optional)

Step 3: Choose Deployment Method
─────────────────────────────────
→ Quick Start: Use workflow UI with manual inputs
→ Config-Based: Edit parameters.json and commit
→ Local: Run PowerShell scripts directly

Step 4: Deploy!
───────────────
Follow the chosen workflow to deploy your Fabric assets.
